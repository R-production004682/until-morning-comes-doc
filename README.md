# 朝が来るまで｜企画資料

ゲーム『朝が来るまで』の企画概要、会議記録、進行フロー、ゲーム仕様をまとめた Obsidian の保管庫（Vault）です。

## Obsidian で開く

1. [Obsidian の公式ダウンロードページ](https://obsidian.md/download)から、使っている OS 向けのデスクトップ版をインストールします。
2. このリポジトリをクローンします。すでに手元にある場合は、そのフォルダを使えます。閲覧だけなら、GitHub の **Code → Download ZIP** からダウンロードして展開する方法もあります。

   ```sh
   git clone https://github.com/R-production004682/until-morning-comes-doc.git
   ```

3. Obsidian を起動し、**Open folder as vault** から、この `README.md` と `ノート/` が入っているフォルダを選びます。別の保管庫が開いている場合は、左下の保管庫メニューから **Manage vaults…** を開きます。[既存のフォルダを保管庫として開く手順](https://obsidian.md/help/manage-vaults)

## 資料の見方

Obsidian 左側のファイル一覧で `ノート/` を開きます。初めて読むときは、企画概要から進むと全体像をつかめます。下のリンクから GitHub 上でも各ノートの本文を開けます。

1. [企画概要](ノート/朝が来るまで｜企画概要.md)で、作品の方向性と舞台設定を確認します。
2. [進行フローとゲーム仕様](ノート/朝が来るまで｜進行フローとゲーム仕様.md)で、探索の順序、エンディングの分岐、操作や演出を確認します。
3. [11月18日の会議記録](ノート/朝が来るまで｜11月18日の会議記録.md)で、打ち合わせ当時の検討内容を確認します。

Obsidian の閲覧ビューでは、本文内のリンクから別のノートへ移動でき、貼り付け画像や進行フローの図も本文中に表示されます。ノート右上のアイコンか `Ctrl+E`（Mac は `Cmd+E`）で閲覧と編集を切り替えられます。[Obsidian の閲覧・編集ビュー](https://obsidian.md/help/edit-and-read)

## フォルダ構成

| フォルダ | 内容 |
| --- | --- |
| `ノート/` | 企画概要、会議記録、進行フローとゲーム仕様 |
| `添付ファイル/` | ノートから参照する貼り付け画像 |
| `図/` | 進行フローの編集用 `.drawio` 原本と、ノートに表示する [SVG](図/朝が来るまで_進行フロー.svg) |

## 編集する場合の設定

**設定 → ファイルとリンク** で、新規ノートと添付ファイルの保存先をそれぞれ **指定したフォルダ** にします。新規ノートには `ノート/`、添付ファイルには `添付ファイル/` を選びます。このリポジトリでは Obsidian の設定を Git の管理対象から外しているため、新しくクローンした環境で設定してください。[Obsidian の「ファイルとリンク」設定](https://obsidian.md/help/settings)

進行フローを修正するときは、`図/` の `.drawio` 原本を編集し、同名の `.svg` も書き出し直します。ノートが参照する画像を追加したら、ノートと画像を一緒にコミットします。

クローン済みの資料を更新するには、このリポジトリのフォルダで `git pull --ff-only` を実行します。
